The working master deliberately retains its Stage 7.4 internal title until the first verified Stage 8 source transformation.

`SEED_MANIFEST.sha256` records the original working master, nine libraries, and
two candle references. It is historical seed evidence, not an ongoing build
manifest; mutable module documentation is deliberately excluded.

`SOURCE_LOCK.json` is the reviewed Stage 8 working lock. Update it with an
approved library/import change; never mutate the protected Stage 7.4 lock.

The active renderer now uses five unique table anchors: three collective
surfaces plus recovered Position and Wave ledgers. Confirmed drawing state is
retained across realtime ticks, and last-only sketches receive a
last-confirmed-history bootstrap after chart reload.
