# PITBULL Stage 5.0 • Parameter Sovereignty

Stage 5.0 separates three concerns that were previously tangled:

1. position quantity
2. TP / SL geometry
3. model importance / ATR horizons

## Position sizing

Every strategy.entry call now sends an explicit `qty`.

Three modes are available:

### Allocation % Equity
Default mode. Restores the intuitive old PITBULL behavior in explicit units.

    allocation cash = strategy.equity * allocation % / 100
    symbol cash     = strategy.convert_to_symbol(allocation cash)
    qty             = symbol cash / (entry price * syminfo.pointvalue)

Default allocation is 10%.

### Risk % Equity

    risk cash       = strategy.equity * risk % / 100
    symbol risk     = strategy.convert_to_symbol(risk cash)
    risk per unit   = stop distance * syminfo.pointvalue
    qty             = symbol risk / risk per unit

This automatically reduces quantity when the stop becomes wider and increases
it when the stop becomes tighter.

### Fixed Qty
Absolute contracts / shares / lots / units.

All modes then pass through user-owned:
- quantity step
- minimum quantity
- optional maximum notional % equity
- optional Governor quantity scaling

Governor quantity scaling is OFF by default.

Same-direction scale-in is OFF by default. If enabled, the add order uses the
user's `Scale-In Quantity X` rather than repeating the whole base quantity.
