# PITBULL Stage 7.0 • Deterministic Artifact Engine

Stage 7.0 introduces a deterministic adaptive macro layer above the federated score pool.

It adds no new front-panel inputs.

The existing pool weights remain visible, but they are now interpreted as priors rather than permanent final coefficients.

A new `ARTIFACT LAB` table appears in the previously unused bottom-right chart slot and reports:

- selected Wizard Hall
- effective period coordinate
- Profitability
- Capital scale
- Action
- Situation
- Items
- Landscape
- Wizard score
- Laboratorium stability
- Experimentarium novelty
- adaptive MA
- adaptive histogram
- adaptive ATR
- channel multiplier
- normalization score/clamp
- adaptive score gate
- Fast/Base/Slow mixture

The artifact is calculated from previous closed-bar data so the macro map does not twitch intrabar.

No library API changed in this stage.
