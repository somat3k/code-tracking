## Geometry grammar

### Circle / Ellipse
The field's outer cycle boundary.
X is structural time in bars.
Y is ATR-normalized price space.

### Spiral
A Fibonacci-turn expansion trajectory inside the same normalized field.
It is not a price prediction. It visualizes how expansion occupies the
available price-time frame.

### Fibonacci Rectangle / Square
The structural leg and Cement target define the outer rectangle.
0.382 and 0.618 divide both time and price.
A centered 0.618 normalized square provides a second internal frame.

### Projection Triangle
A = structural Fib anchor
B = structural Fib end
C = fused Cement target

### ATR / Jitter Vector
Starts at the live candle.
Direction combines:
- normalized price velocity
- acceleration
- wick asymmetry
- Wave field direction
- Cement direction
- current body direction

Length reacts to:
- ATR expansion
- body pressure
- jitter
