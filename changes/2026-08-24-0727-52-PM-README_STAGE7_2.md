# PITBULL Stage 7.2

This packet solves the oversized-snippet problem without cutting methodology.

### What changed

- Root Clock / Artifact implementation moved into `PB_ArtifactCore_v1.pine`.
- Generic committed value transport added in `PB_SliceTransport_v1.pine`.
- Artifact telemetry is written into one persistent Slice on confirmed bars.
- Artifact Lab reads key public values from that Slice.
- The remaining master is split into eight deterministic development shards.
- `build_master.py` reconstructs the authoritative master byte-for-byte from those shards.

### Normal workflow

Do not exchange the full master during ordinary sessions.

If we are changing Spiral/Fork/geometry, share or patch `05_MEASURE_DRAWINGS.pine.part`.
If we are changing pool/macro orchestration, use `02_ENGINES_ARTIFACT_POOL.pine.part`.
If we are changing tables, use `07_TABLES_OUTPUTS.pine.part`.

Then rebuild and compile the generated master.
