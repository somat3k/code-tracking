# PITBULL Stage 5.1 • Federated Score Pool

This package refactors the supplied `Pasted text(10).txt` master into independent strategy-plane voting.

## What changed

The existing engines still calculate their full state, but final direction no longer comes directly from the legacy Router.

Each strategy plane publishes one score into a cumulative pool. Every plane has a top-level ON/OFF toggle and global weight. An OFF plane is removed from the pool denominator.

The pool automatically discounts highly similar active scores, reducing repeated evidence without adding another user tuning parameter.

The final flow is:

`existing controllers -> plane scores -> federated pool -> Governor -> execution`

## Compatibility

The complete old Router remains available as the `Legacy Router` plane and defaults OFF.

Geometry remains fully rendered as before. Its new voting plane also defaults OFF because Geometry was previously projection-only.

## Publishing

This package changes only the master strategy source. It does not require a new library publication if the import versions at the top of the supplied script are already valid in your TradingView account.

TradingView compilation remains authoritative.
