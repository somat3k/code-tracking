# PITBULL Pine Library Migration • Stage 1

## Files

- `PB_Types_v1.pine`
- `PB_Math_v1.pine`
- `PB_Performer_v1.pine`
- `PITBULL_Main_Stage1.pine`

## TradingView publish order

1. Create a new Library and paste `PB_Types_v1.pine`.
   Publish as `PB_Types`, version 1.

2. Create a new Library and paste `PB_Math_v1.pine`.
   Publish as `PB_Math`, version 1.

3. Create a new Library and paste `PB_Performer_v1.pine`.
   Its import currently assumes the TradingView username:
   `ClassicPotatoChamberXII`.
   If your TradingView username differs, replace that identifier in the import.
   Publish as `PB_Performer`, version 1.

4. Paste `PITBULL_Main_Stage1.pine` into a new Strategy.
   Replace the same username in its Performer import if necessary.

## Control philosophy

The strategy owns:
- `input.*()`
- `strategy()`
- `strategy.entry/exit/close`
- plots/tables/draw orchestration
- library version selection

Libraries own:
- calculation
- classification
- state conversion
- reusable geometry math

The Performer returns a State object. It does not place orders.
