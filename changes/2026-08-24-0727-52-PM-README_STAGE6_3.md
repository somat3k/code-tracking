# PITBULL Stage 6.3 • High-End Box Architecture

Stage 6.3 makes boxes part of one coherent visual language instead of a collection of unrelated rectangles.

## CARD

Fork, Wave, Signal and Position packets use one persistent card primitive.

Cards now use:
- semantic transparent fill
- restrained semantic border
- monospace telemetry
- automatic wrapping
- closed-bar updates
- persistent handles

Position gets a slightly stronger frame so an active trade is visually distinct without becoming a billboard.

## ZONE

FVG, score, risk and reward rectangles are treated as market zones.

Fresh FVG uses a dashed border. Partial FVG becomes dotted and visually fades, so lifecycle is visible without reading the label.

The score zone changes border strength with pool confidence. It does not add another object.

Position risk/reward zones are projected slightly into future chart space using the existing projection setting. This separates the active plan from candle clutter.

## HALO

FVG/iFVG halos are intentionally almost transparent. Their job is spatial emphasis, not another rectangle competing with the actual gap.

## FIELD

The Dimensional Field screen becomes a ghosted dotted boundary. Internal Fibonacci/triangle/circle/spiral methodology is untouched.

## Processing

No extra box objects were introduced.

The main persistent box primitives now update coordinates with:
- `box.set_lefttop()`
- `box.set_rightbottom()`

rather than four independent edge mutations.

Everything remains on the closed-bar visual latch from Stage 6.1.
