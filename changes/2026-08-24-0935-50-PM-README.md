# Stage 8 modules

These 13 ordered `.pine.part` files are the editable source of the generated working master. Their initial contents are byte slices of the protected Stage 7.4 Session 3 master; no separators are inserted during assembly.

`BASELINE_MODULE_MANIFEST.json` records the immutable seed boundaries and hashes. `BUILD_MANIFEST.json` records the current module, library, builder, and generated-master hashes. Only `tools/build_stage8.py bootstrap --force` restores the protected seed and can overwrite module edits; normal development uses `build` and `build --check`.

The Session 2 shards under the protected baseline remain reference material only. They are not an exact build source for Session 3.

Stage 8 HA Volume ownership stays within the fixed inventory: inputs live in
`01_FOUNDATION_POOL.pine.part`, while time-coordinate registry helpers and the
confirmed visual packet live in `04A_RENDER_REGISTRY.pine.part`. Do not add a
fourteenth shard without first revising the protected seed/build contract.
