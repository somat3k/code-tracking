# Session 3 • PLOT-SAVE Registry + Position v2

This session makes the drawing registry real.

## PLOT-SAVE Phase 1

Position is the first migrated family. Objects are no longer identified only
by scattered global handles. Each registered object has:

- key
- family
- priority
- birth bar
- TradingView handle

The registry can update, clear, prune and count families.

## Position v2

The chart keeps the spatial information:

- reward/risk corridor
- entry
- stop
- target
- current price
- confirmed-bar trace
- small historical exit marks

The old floating position card is removed.

The Position Ledger at top-right owns explanatory data, including Wave v3,
Ichimoku time assessment, MFE/MAE and PLOT-SAVE counts.

## Migration strategy

Do not migrate every drawing family at once.

Recommended order:
1. Position (this session)
2. Wave + Wave-Time
3. Wedge + Fib
4. FVG / iFVG
5. Structure / pivots
6. Geometry field

That keeps compiler/debugging failures isolated by family.

No library API changes are required in Session 3.
PB_Waves/5 remains the expected Wave import.
