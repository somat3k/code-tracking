# Project direction

## Protected identity

PITBULL remains one Pine v6 strategy with:

- independently calculated strategy planes;
- one normalized collective score;
- one Governor and one execution owner;
- a persistent, closed-bar chart language;
- an independent drawing kernel;
- the top/left/bottom Edge Board frame;
- high-information cards with concise visible text and detailed tooltips.

The Stage 7.4 appearance and organization are the default reference. Stage 8 is an extension of that system, not a redesign.

## Stage 8 direction

1. Preserve the existing 13 score planes.
2. Add dedicated Breakout and causal Kernel planes.
3. Upgrade Orderflow with Heikin Ashi body/wick and volume-candle evidence.
4. Add `All / Custom / None` participation control while retaining individual toggles.
5. Ensure disabled planes cannot influence the pool indirectly.
6. Make confirmed MTF data the default for execution.
7. Route every mutable drawing through one bounded renderer.
8. Keep the three-table Edge Board and evolve its card models without changing its frame.
9. Produce separate Core and Premium Footprint builds from the same source line.
10. Treat TradingView compilation and chart behavior as release gates.

## Non-negotiable rules

- No strategy plane places orders directly.
- Heikin Ashi prices are visual/evidence data, never assumed to be real fills.
- No centered/future kernel value enters an order decision.
- No new unbounded historical drawing arrays.
- No raw drawing constructor outside the renderer ownership layer in Stage 8.
- No generated master is hand-edited after deterministic sharding is restored.
- No file under `versions/` is edited.
- No feature is removed merely to make room without a recorded request and baseline comparison.
